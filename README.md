# 🐦 Flappy Sky

A simple Flappy Bird-style browser game made with **HTML, CSS, and JavaScript**.

## 🎮 How to Play

Fly the bird through the pipes without hitting them.

### Controls

- **Space** — Flap
- **Arrow Up** — Flap
- **Mouse Click** — Flap
- **Touch** — Flap on mobile

Try to get the highest score possible!

## ✨ Features

- 🐦 Playable bird
- 🟩 Moving pipes
- 🏆 Score system
- 💾 Local high-score saving
- ☁️ Animated clouds
- 🌄 Cartoon-style scenery
- ✨ Particle effects
- 📱 Touch controls
- 💻 Keyboard and mouse controls
- 🔄 Restart system
- 📐 Responsive game window
